# 我的電影片單

以繁體中文記錄我看過的電影。首頁用海報卡片瀏覽，選取電影後進入獨立詳情頁，閱讀基本資料、劇情簡介、個人觀後感、評分和觀影資訊。

## 開啟網站

直接以瀏覽器開啟 `index.html` 即可瀏覽；本專案不需安裝依賴或建置。部署到 GitHub Pages 時，將整個資料夾內容推送到 Repository，再於 Repository 設定中啟用 Pages。

## 更新片單

依照 `AGENTS.md` 的資料格式編輯 `data/movies.js`。新增電影時填入唯一 `id`，觀後感、評分與實際觀影日期只填使用者提供的內容；未知資料可以留空。首頁會自動產生電影卡片，詳情頁網址格式為 `movie.html?id=<id>`。

## 海報

`assets/posters/` 預留放置海報圖片。每部電影目前使用遠端海報連結，載入失敗時會自動改用網站內建的文字封面。若要讓網站離線也能顯示海報，可將已確認可使用的圖片放進此資料夾，並在 `data/movies.js` 將該筆的 `poster` 設為相對路徑。
